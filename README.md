# Todo App

A responsive Todo application built using HTML, CSS and JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Enter key support for quick task creation
- Responsive layout
- Custom styled scrollbar
- Background image UI
- Task completion visual state

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
